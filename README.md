# Devora — Conversor efímero a Markdown

Devora documentos, sirve Markdown, no guarda nada. Herramienta web accesible
que convierte PDF, Word, PowerPoint y más a Markdown para reutilizarlo en
modelos o agentes de IA, sin base de datos ni retención.

- **Local:** ver [README-local.md](README-local.md)
- **Fidelidad por formato:** ver [docs/fidelidad.md](docs/fidelidad.md)
- **Flujo git:** ver [docs/git.md](docs/git.md)
- **Despliegue:** Render Free vía `render.yaml` (servicio `devora`)
